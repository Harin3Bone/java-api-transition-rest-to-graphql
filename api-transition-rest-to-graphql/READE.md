# API Transition REST to GraphQL

## Description

This project is an **Independent Study (IS)** developed as part of a university curriculum.
It focuses on designing and implementing a compiler transition layer that converts
**RESTful API** architecture into **GraphQL API** architecture.

This project aims to reduce the complexity and effort involved in adopting GraphQL
for teams that already have an established REST API infrastructure. By analyzes existing 
REST API endpoints and automatically generates corresponding GraphQL schemas, queries, mutations, and resolvers

## Condition

This project is developed as an Independent Study (IS), which means this won't be support for all languages and frameworks,
but the project will focus on a specific language and framework.

1. Language: Java 17+
2. Framework: Spring Boot 3.0+
3. Build Tool: Maven 3+
